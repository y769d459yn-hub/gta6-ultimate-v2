Codes de triche GTA 6

Les 19 codes de triche de GTA 6 (PS5 et Xbox) dont la combinaison est connue. Pour chaque code : ce qu'il fait, comment le débloquer et les flèches à taper. Les codes dont la combinaison n'a pas encore été découverte ne sont pas listés : ils seront ajoutés dès qu'elle sera trouvée.

  1. 1Termine l'histoire La liste des codes apparaît dans le menu Progression.
  2. 2Débloque le code Chaque code a son défi (sport, tir, collection…).
  3. 3Tape-le au téléphone Sors le téléphone, maintiens L1 et appuie sur R1 (PS5) ou LB + RB (Xbox), puis tape les flèches avec la croix.

Un code actif bloque la sauvegarde et les trophées jusqu'à ce que tu quittes le jeu. Sauvegarde avant d'utiliser un code. Les codes sont les mêmes sur PS5 et Xbox ; il n'y a pas encore de version PC.

Questions fréquentes

Pourquoi mon code ne marche pas ?

Un code ne fonctionne que s'il est débloqué : termine d'abord l'histoire, puis réussis son défi (indiqué sous chaque code). Vérifie aussi que tu maintiens bien L1 (ou LB) en appuyant sur R1 (ou RB) avant de taper les flèches.

Est-ce que les codes bloquent les trophées ?

Oui, mais seulement pendant la session : tant qu'un code est actif, tu ne peux ni sauvegarder ni gagner de trophées. Quitte le jeu et recharge ta sauvegarde pour revenir à la normale. Ce que tu as fait pendant que le code était actif n'est pas gardé.

Y a-t-il un code d'invincibilité ou de santé ?

Non. Aucun code connu ne rend invincible et il n'y a pas de code de santé.

Et sur PC ?

GTA 6 n'est sorti que sur PS5 et Xbox Series. Les combinaisons utilisent seulement la croix directionnelle : elles sont identiques sur les deux consoles.
