Comment sauvegarder dans GTA 6 ?

Réponse

Hors mission : menu Pause, puis Jeu, puis Sauvegarder. Le jeu sauvegarde aussi tout seul à la fin de chaque mission.

Voir la solution

Étapes

  1. 1Termine ou quitte la mission en cours.
  2. 2Ouvre Pause, puis Jeu, puis Sauvegarder.
  3. 3Ou dors dans le lit d'une planque : ça sauvegarde aussi.

À savoir : Impossible de sauvegarder pendant la plupart des missions. Les sources ne donnent pas toutes la même méthode.
