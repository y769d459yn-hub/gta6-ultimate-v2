Tous les codes de coffres de GTA 6

En bref

Ça dépend du coffre. Les coffres des braquages (magasins, banques, bijouteries) changent de code à chaque partie et même à chaque braquage : cherche la note avec le mode Focus. Les coffres des repaires de gangs, des lieux secrets et de certaines missions ont un code fixe : ils sont listés ci-dessous.

Coffre de braquage : comment trouver le code

  1. 1Active le mode Focus (les deux sticks en même temps) près du coffre.
  2. 2Cherche la note surlignée : post-it, écran d'ordinateur, papier sur un garde à terre.
  3. 3Pas de note ? Les petits coffres se crochètent et les caisses se forcent.
  4. 4Les codes des braquages changent à chaque fois : une liste trouvée sur Internet ne marchera pas.

Questions fréquentes

Pourquoi le code trouvé sur Internet ne marche pas ?

Parce que les coffres de braquage (magasins, banques, bijouteries hors missions) changent de code à chaque partie. Seuls les coffres des repaires de gangs, des lieux secrets et des missions gardent le même code.

Peut-on ouvrir un coffre sans le code ?

Les petits coffres se crochètent et les caisses se forcent. Les grands coffres demandent le code : cherche la note avec le mode Focus.
